# Ref2VA Prompt Structure Guide

This guide defines the exact output format for each segment prompt generated by the character-interactive-explainer Skill. Follow this template precisely.

## When to Use This Guide

Read this file when:
- Writing the final Ref2VA prompt for any segment
- You need the exact field order and formatting rules
- You need to verify that a generated prompt is structurally correct

## Template

Each segment prompt must contain these six sections in this exact order:

`
subject_definitions:
<Subject 1> is [character description from Picture 1, including: ethnicity, age category, hair style and color, glasses and accessories, outfit color and style, jewelry, makeup style]. She/He is the presenter named [presenter name].
<Subject 2> is [environment description from Picture 2, including: desk type and color, laptop/computer, lighting fixtures, chair, shelves, flowers/plants, wall decor, books, overall color palette, ambience].
<Picture 1> is the presenter reference image, defining the character identity, facial structure, hairstyle, glasses, wardrobe, and accessories for all shots in this segment.
<Picture 2> is the environment reference image, defining the room layout, color palette, furniture, decor, and lighting mood for all shots in this segment.

summary:
[reference generation] The target video shows <Subject 1> ([presenter name]) [doing what, where] with [holographic interaction description]. <Picture 1> provides the character appearance and wardrobe reference. <Picture 2> provides the environment and lighting reference. [One-sentence summary of segment content and duration].

retention_analysis:
<Subject 1> (appears in [list all shots]): fully_preserved - [list what is preserved: face structure, hairstyle, glasses, outfit, accessories, identity].
<Subject 2> (appears in [list all shots]): fully_preserved - [list what is preserved: desk, laptop, lamp, chair, shelves, flowers, lighting].
<Picture 1> (character reference): fully_preserved - [confirm consistent application].
<Picture 2> (environment reference): fully_preserved - [confirm consistent application].

detailed_description:
The target video is in a [style: cinematic live-action / 3D CG / etc.] style with [lighting description], [depth of field], and [atmosphere description], [continuity note if segment 2+].
[Shot 1] [Shot description: composition, subject position, environment, action, camera motion, holographic elements, dialogue or voiceover with <d> tags. Include hologram summon/interact/respond/exit choreography.]
[Shot 2] At [MM:SS.mmm], the shot cuts to [next shot description...]
[Shot 3] At [MM:SS.mmm], the shot cuts to [next shot description...]
[Shot 4] At [MM:SS.mmm], the shot cuts to [next shot description...]

overall_soundscape:
[1-4 English sentences summarizing ambient sound, physical action sounds, holographic UI sounds, and non-verbal human sounds across the full segment. Do not repeat dialogue here.]

non_diegetic_music:
[1-3 English sentences describing background music: instrumentation, tempo, rhythm, dynamic changes. Use N/A if no music.]
`

## Field Rules

### subject_definitions
- <Subject 1> = the character/presenter. Always derived from Picture 1.
- <Subject 2> = the environment/room. Always derived from Picture 2.
- <Picture 1> and <Picture 2> = standalone entries stating their reference role.
- Keep labels consistent across all segments: Subject 1, Subject 2, Picture 1, Picture 2.
- Do not create additional subjects unless the content requires a second character.

### summary
- Must start with a task-type prefix in square brackets: [reference generation] for standard generation tasks.
- Use one English paragraph.
- Reference all labels: <Subject 1>, <Subject 2>, <Picture 1>, <Picture 2>.
- State the segment duration.

### retention_analysis
- One line per reference label.
- Use ully_preserved when the reference is consistently applied.
- Use partially_preserved only when some defined characteristics are intentionally changed.
- List which specific attributes are preserved.

### detailed_description
- Write in English. Preserve dialogue/lyrics/visible text in original language.
- Open with 1-2 style sentences before [Shot 1].
- [Shot 1] has no timestamp. Later shots: [Shot N] At MM:SS.mmm, ...
- Timestamps must be strictly increasing and within the segment duration.
- Camera motion: write as natural English action (type + amplitude + speed).
- Speaker ID: (S1) for the presenter, stable across all segments.
- Dialogue: <d>[Language] exact words</d> — verbatim, no translation.
- Voiceover: use "says in an off-screen voiceover" + "while her/his lips remain completely closed".
- Visible text: English double quotation marks (e.g., "16GB VRAM").
- Holographic choreography: for each hologram, describe summon, interact, respond, exit.
- Target 350-500 English words for generation tasks.

### overall_soundscape
- 1-4 English sentences, one paragraph.
- Summarize ambient + physical + holographic UI sounds.
- Do not repeat dialogue or music here.

### non_diegetic_music
- 1-3 English sentences.
- Focus on instrumentation, tempo, rhythm, dynamics.
- Use N/A when no background music.

## Shot Count and Pacing

For a 15-second segment:
- 3-5 shots
- Shot 1: 0-4s (hook + establish)
- Shot 2: 4-8s (explain + first hologram)
- Shot 3: 8-12s (detail + analogy + main hologram)
- Shot 4: 12-15s (transition/close + hologram dissolve)

For a 10-second segment:
- 2-3 shots
- Shot 1: 0-4s
- Shot 2: 4-8s
- Shot 3: 8-10s

For a 20-second segment:
- 4-6 shots
- Adjust timestamps proportionally

## Holographic Description Vocabulary

### Summon
- materializes, fades in, appears, expands from a point, slides in, pops up, bursts into view
- "A holographic panel in pale pink and rose gold materializes above the laptop"

### Interact
- taps, pinches, flips, swipes, tosses, rotates, expands, presses, waves hand across
- "She reaches out and taps the holographic button with her fingertip"

### Respond
- flips to reveal, expands, pulses with light, changes color, rotates, dissolves into particles, shrinks
- "The card flips to reveal faint text: ..."

### Exit
- dissolves into particles, fades away, shrinks to a point, flies off-screen, scatters
- "It dissolves into pink-gold particles that drift upward"

## Continuity Checklist Across Segments

Verify before outputting:
- [ ] Same <Subject 1> description in every segment
- [ ] Same <Subject 2> description in every segment
- [ ] Same presenter name
- [ ] Same outfit, glasses, hairstyle, accessories
- [ ] Same room layout, furniture, color palette
- [ ] Same holographic design system (colors, style, interaction patterns)
- [ ] Same lighting mood
- [ ] Same speaker ID (S1)
- [ ] Same audio style (ambient music, UI sounds, room tone)
- [ ] Segment 2+ references continuity from the previous segment
