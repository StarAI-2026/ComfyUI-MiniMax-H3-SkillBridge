# 角色交互演示生成器

将任意主题转化为多段 H3 视频提示词，包含角色讲师、锁定环境、全息交互 UI、打比方和清晰旁白。每段提示词是独立的 Ref2VA 格式，保持角色身份、环境、灯光和全息风格一致。

## 适用场景

- 角色讲师配合全息 UI 交互讲解主题
- 产品教程或技术指南需要高质量短视频格式
- 知识科普使用比方和视觉隐喻
- 硬件/软件推荐需要分级对比卡片
- 多段视频需要角色和环境一致性

不适用：
- 无角色参考图（使用 T2VA 类 skill）
- 无讲师的纯空镜旁白
- 仅需脚本不需视频提示词

## 输入要求

必须提供：
1. **角色参考图**（Picture 1）：定义讲师身份、面部、发型、眼镜、服装、配饰。
2. **环境参考图**（Picture 2）：定义房间布局、色调、家具、灯光氛围。
3. **主题和要点**：要讲解的内容，可选结构（钩子、对比、推荐、行动号召）。
4. **讲师名称**（可选）：出镜身份，默认为"讲师"。

可选输入：
- 风格方向：成熟、休闲、专业、活泼、性感但专业
- 段数和时长：默认2段×15秒
- 画幅比例：默认9:16竖屏
- 旁白语言：默认中文
- 比方主题：旅行、烹饪、工具、运动等

## 步骤1：解析与分段

将主题分为N段（默认2段）。每段必须：
- 有明确叙事目的（钩子、解释、对比、推荐、收尾）
- 在时间预算内（默认每段15秒）
- 以过渡钩子或收尾陈述结束
- 包含3-5个镜头，有不同角度和全息交互

每段提取：
- 核心信息：观众应学到什么
- 情绪节拍：好奇、挑战、安心、果断
- 关键数据点：数字、档位、步骤、对比
- 比方候选：来自日常生活的具体隐喻
- 全息元素：展示什么 UI 卡片、面板或数据可视化

## 步骤2：角色与环境锁定

### 角色锁定
- 角色参考图是所有段的身份锚点。
- 保持：面部结构、发型、眼型、眼镜、配饰、服装颜色和款式。
- 风格方向仅影响表演，不影响外观：
  - **成熟**：平静眼神、柔和微笑、从容节奏、优雅手势
  - **休闲**：放松姿态、更暖的表情、对话式手势
  - **专业**：挺直姿态、直视镜头、精准手势
  - **活泼**：更轻快的表情、更快的动作、动画式手势
  - **性感但专业**：亲密温暖、磁性气场、克制优雅
- 不得改变年龄段、种族、眼镜、服装色系或可辨识身份。

### 环境锁定
- 环境参考图是所有段的场景锚点。
- 保持：房间布局、色调、家具、装饰、灯光氛围。
- 延伸为电影级实景空间，非产品照片。
- 讲师须真实存在于房间：反射、接触阴影、暖色弹光。

## 步骤3：设计全息交互

每段必须包含可交互的全息 UI 元素，非装饰性。

### 全息设计规则
- 全息影像悬浮在桌面/笔记本/工作区上方或旁边。
- 讲师与之交互：指向、捏合、旋转、展开、翻转、抛掷、滑动。
- 色调：从环境派生（如粉色房间→粉金色，科技实验室→蓝银色）。
- 全息影像不得喧宾夺主，是辅助元素。
- 全息文字简短可读：标签、数字、短词组，非段落。

### 全息类型库
| 类型 | 用途 | 示例 |
|------|------|------|
| 进度条 | 安装、加载、时间线 | 下载进度、步骤完成 |
| 卡片组 | 多项、档位、选项 | 硬件档位、功能对比 |
| 数据面板 | 统计、规格、数字 | 显存/内存规格、跑分 |
| 流程图 | 过程、管线、步骤 | 安装流程、工作流步骤 |
| 警告图标 | 注意、误区 | "8GB能跑...但代价是？" |
| 确认徽章 | 成功、完成 | "就绪！""完成！" |
| 时间线条带 | 顺序事件、历史 | 版本历史、发布时间线 |
| 对比面板 | 并排对比 | 前/后、档位A vs B vs C |

### 交互编排
每个全息元素出现时，指定：
1. **召唤**：如何出现（物质化、展开、滑入、弹出）
2. **交互**：讲师做什么（点击、捏合、翻转、滑动、抛掷）
3. **响应**：如何反应（翻转、展开、溶解、脉冲、变色）
4. **退出**：如何离开（粒子溶解、缩小、飞走、淡出）

## 步骤4：生成比方

每段至少包含一个比方，将抽象内容具象化。

### 比方框架
1. 识别抽象概念（如"硬件要求""安装流程"）
2. 映射到熟悉领域（旅行、烹饪、工具、运动、购物、建造）
3. 创建保持关键关系的比较：
   - 低端 = 经济/基础/入门
   - 中端 = 均衡/舒适/性价比
   - 高端 = 顶级/头等/强力
4. 将比方写为旁白台词
5. 设计强化比方全息视觉（如座椅图标、行李箱、工具箱）

### 比方质量检查
- 比喻直观吗？（观众不加解释就能理解？）
- 保持了关键关系吗？（低端仍然感觉低端？）
- 对目标受众文化合适吗？
- 避免误导性暗示？

## 步骤5：撰写旁白脚本

每段旁白遵循以下规则：

- 旁白语言：默认中文，除非用户指定
- 每个旁白节拍须在时间码内（约2-3秒一句）
- 使用讲师声音特质：成熟风格为温暖、亲密、从容
- 自然融入比方
- 每段以过渡钩子或收尾陈述结束
- 标注旁白vs对镜说话：
  - 对镜：(S1) says: <d>[Chinese] ...</d>
  - 旁白：(S1) says in an off-screen voiceover: <d>[Chinese] ...</d> while her lips remain completely closed.

### 脚本节奏指南（每15秒段落）
| 时间 | 节拍 | 目的 |
|------|------|------|
| 0-3秒 | 钩子 | 抓住注意力，点明主题 |
| 3-8秒 | 解释 | 核心内容配全息支持 |
| 8-12秒 | 细节 | 数据、对比或比方 |
| 12-15秒 | 过渡 | 钩接下一段或收尾 |

## 步骤6：输出 H3 Ref2VA 提示词

读取 eferences/prompt-structure-guide.md 获取完整 Ref2VA 模板。

每段输出一个完整的 Ref2VA 提示词，包含：
1. subject_definitions：定义 Subject 1（角色）、Subject 2（环境）、Picture 1、Picture 2
2. summary：一段带任务类型前缀的摘要
3. etention_analysis：每个参考的保留方式
4. detailed_description：逐镜头描述，含镜头、对话、全息
5. overall_soundscape：环境音和物理音
6. 
on_diegetic_music：背景音乐描述

### 镜头写作规则
- [Shot 1] 无时间码；后续镜头用 [Shot N] At MM:SS.mmm, ...
- 镜头运动：类型+幅度+速度（如"pushes in with small amplitude at slow speed"）
- 说话者ID：(S1) 为讲师，跨段稳定
- 对话：<d>[语言] 原文</d> — 逐字保留，不翻译
- 可见文字：英文双引号（如 "16GB VRAM"）
- 全息描述：指定每个元素的召唤、交互、响应、退出
- 转场：软甩镜头、全息擦除、匹配剪辑或发光数据带

## 镜头与表演语言

- 第1段通常以中近景开场，然后进入过肩镜头和全景。
- 后续段使用更多正面构图、受控推拉和全息转场。
- 讲师在面向镜头说话、指向工作区和操作全息卡片之间交替。
- 动作优雅克制；不乱挥手臂，不夸张姿势。
- 跨段连续性：同一房间、同一服装、同一眼镜、同一全息设计系统。

## 音频设计

- 温暖、近距离、亲密的录音棚旁白/讲师声音。
- 柔和氛围音乐匹配环境氛围，低音量。
- 精致的全息 UI 提示音和交互声。
- 环境房间音：台灯嗡鸣、椅子轻响、衣物摩擦。
- 避免大声通知、刺耳谁osh声或喜剧音效。

## 技术质量标准

- 默认9:16竖屏，除非用户指定。
- 匹配环境参考的电影级灯光。
- 浅景深，干净背景分离。
- 全息文字简短可读，不堆砌长段落。
- 保持连续性：跨段同一房间、服装、眼镜、发型、全息设计。

## 拒绝或重写条件

- 输出是一个通用提示词而非N段独立提示词。
- 忽略角色参考图、环境参考图、全息交互或比方。
- 改变角色身份、年龄、种族、眼镜或服装色系。
- 将环境改为普通办公室或摄影棚。
- 使用露骨色情措辞或不专业姿势。
- 旁白节拍过长无法适配时间码。
- 全息影像仅为装饰，无讲师交互。
- 比方具有误导性、文化不当或过于抽象。
