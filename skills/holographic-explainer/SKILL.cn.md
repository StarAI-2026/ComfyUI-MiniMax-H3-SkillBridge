# 全息讲解

将用户提供的文案和参考图转化为多段 H3 视频提示词，包含角色讲师、全息UI交互和完整旁白覆盖。每段是独立的 Ref2VA 格式提示词。本 Skill 完全自包含，不依赖任何外部 skill。

## 适用场景

- 角色讲师配合全息UI交互讲解主题
- 产品教程、技术指南、知识科普需要高质量短视频提示词
- 文案需要拆分为定时段落且完整覆盖
- 硬件/软件对比需要全息可视化

不适用：
- 无角色参考图
- 无讲师的纯空镜旁白
- 仅需脚本不需视频提示词

## 必需输入

用户必须提供：
1. **角色参考图**（Picture 1）：定义讲师身份、面部、发型、眼镜、服装、配饰。
2. **环境参考图**（Picture 2）：定义房间布局、色调、家具、灯光氛围。
3. **文案**：需要跨所有段完整朗读的文本。

可选输入：
- **讲师名称**：出镜身份，默认"讲师"。
- **段最大时长**：默认15秒，用户可指定任意值。
- **旁白音频时长**：如提供，用于计算实际语速。
- **语速**：如用户直接指定（如"每秒4字"），跳过估算。
- **风格方向**：用户自由表达（如成熟、休闲、专业、活泼、性感但专业）。仅影响表演，不影响外观。
- **画幅比例**：用户在视频生成软件中自行设置，Skill 不硬编码。
- **旁白语言**：默认中文。

## 步骤1：解析输入

### 1.1 提取角色身份（从 Picture 1）

必须描述以下属性：
- 种族和年龄段
- 发型：款式、长度、颜色、显著特征（丝带、蝴蝶结等）
- 眼镜：框型、颜色、链饰或挂绳
- 上衣：颜色、款式、领口
- 配饰：首饰、项链、丝带
- 妆容风格：自然、浓艳、奢华

### 1.2 提取环境（从 Picture 2）

必须描述以下属性：
- 桌面：类型、颜色、形状
- 电脑/设备：类型、颜色
- 灯光：灯具类型、灯罩颜色、LED灯带、氛围
- 椅子：材质、颜色、底座
- 书架：类型、内容
- 花卉/植物：类型、颜色
- 墙面装饰：挂画、标牌
- 整体色调和氛围

### 1.3 解析文案

- 逐字保留原文
- 按 `references/narration-budget-guide.md` 中的规则计算总字数
- 识别内容特征：技术密度、口语标记、情绪标记

### 1.4 确定风格

- 如用户提供风格描述，则读取
- 不强加固定风格，用户自由表达
- 风格仅影响表演和旁白表达，不影响角色外观

## 步骤2：计算旁白预算

读取 `references/narration-budget-guide.md` 获取完整指南。

### 2.1 确定语速

优先级：
1. 用户提供音频时长：`语速 = 总字数 / 音频时长`
2. 用户直接指定语速：使用该值
3. 否则：根据内容密度估算（见 narration-budget-guide.md）

### 2.2 计算每段预算

```
全息停顿总时长 = 该段所有全息互动停顿之和
            （最少2次互动，每次0.5-2.0秒，视复杂度而定）
可用字数 = 语速 × (段最大时长 - 全息停顿总时长)
```

### 2.3 输出预算表

| 参数 | 值 |
|------|-----|
| 文案总字数 | XXX |
| 语速 | X.X 字/秒 |
| 段最大时长 | XX 秒 |
| 每段全息停顿 | X.X 秒 |
| 每段可用字数 | XX |

## 步骤3：文案拆段

读取 `references/narration-budget-guide.md` 获取完整拆段算法。

### 3.1 语义切分

1. 按标点（句号、问号、感叹号、分号）将文案切分为句子单元
2. 按计字规则计算每句字数
3. 贪心装箱：逐句累加，接近可用字数时在最近语义断点分段

### 3.2 长句处理

- 单句字数 > 可用字数时，在逗号处拆分
- 后半段放入下一段
- 下一段开头可添加过渡词（计入预算）

### 3.3 口语化微调

允许的调整（不得改变意思）：
- 添加语气词填充预算："对吧""你看""其实"
- 删减冗余虚词节省预算："的""了""一下"
- 调整语序使口播更自然

### 3.4 输出拆段表

```
| 段号 | 字数 | 旁白时长 | 全息停顿 | 总时长 | 旁白内容 |
|------|------|---------|---------|--------|----------|
| 1    | XX   | XX.X秒  | X.X秒   | XX.X秒 | "..."    |
| 2    | XX   | XX.X秒  | X.X秒   | XX.X秒 | "..."    |
```

### 3.5 校验

- 每段总时长 ≤ 段最大时长
- 所有段拼接 = 原文100%（含允许的微调）
- 无句子被中间截断（长句逗号拆分除外）

## 步骤4：设计全息交互

读取 `references/hologram-library.md` 获取完整类型库和词汇。

### 4.1 最低要求

- 每段至少2个全息互动元素
- 相邻段尽量使用不同类型组合

### 4.2 内容匹配

根据每段旁白内容选择全息类型：
- 数字/规格 -> 数据面板、卡片组
- 步骤/流程 -> 流程图、进度条
- 对比/选择 -> 对比面板、卡片组
- 警告/质疑 -> 警告图标、翻转卡片
- 结果/完成 -> 确认徽章、图表曲线
- 历史/版本 -> 时间线条带
- 产品/型号 -> 3D模型旋转、数据面板
- 趋势/性能 -> 图表曲线
- 架构/关系 -> 地图/拓扑
- 特性/关键词 -> 标签云

### 4.3 编排每个全息元素

每个全息元素必须指定四步：
1. **召唤**：如何出现（物质化、淡入、弹出、滑入...）
2. **交互**：讲师做什么（点击、捏合、翻转、滑动...）
3. **响应**：如何反应（翻面揭示、展开、脉冲发光、变色...）
4. **退出**：如何离开（粒子溶解、淡出、缩小消失...）

### 4.4 派生色调

- 从环境参考图（Picture 2）提取主色调
- 按 `references/hologram-library.md` 中的色调规则映射到全息色调
- 全息色调跨所有段保持一致

### 4.5 输出全息设计表

```
| 段号 | 全息ID | 类型 | 内容 | 召唤 | 交互 | 响应 | 退出 | 时长 |
|------|--------|------|------|------|------|------|------|------|
| 1    | H1     | ...  | ...  | ...  | ...  | ...  | ...  | X.X秒|
| 1    | H2     | ...  | ...  | ...  | ...  | ...  | ...  | X.X秒|
| 2    | H3     | ...  | ...  | ...  | ...  | ...  | ...  | X.X秒|
| 2    | H4     | ...  | ...  | ...  | ...  | ...  | ...  | X.X秒|
```

## 步骤5：生成 Ref2VA 提示词

读取 `references/ref2va-format-guide.md` 获取完整格式规范。

每段输出一个完整的 Ref2VA 提示词，包含六个字段：

### 5.1 subject_definitions

定义 Subject 1（角色）、Subject 2（环境）、Picture 1、Picture 2。
- 跨所有段保持定义一致
- 从步骤1.1提取角色描述
- 从步骤1.2提取环境描述

### 5.2 summary

一段英文摘要，以 `[reference generation]` 前缀开头。
- 说明讲师做什么、在哪、配合什么全息
- 引用所有标签：<Subject 1>、<Subject 2>、<Picture 1>、<Picture 2>
- 注明该段时长

### 5.3 retention_analysis

每个参考标签一行，均为 `fully_preserved`。
- 列出保留的具体属性

### 5.4 detailed_description

主正文。遵循以下规则：

**开头**：[Shot 1]之前1-2句英文风格描述。第2段及之后添加"continuing seamlessly from the previous segment"。

**镜头**：每段3-4个镜头。
- `[Shot 1]` 无时间码
- 后续镜头：`[Shot N] At MM:SS.mmm, the shot cuts to...`
- 时间码严格递增，在0到段最大时长内

**镜头运动**：类型+幅度+速度，写为自然英文动作。

**说话者**：`(S1)` 为讲师，跨段稳定。

**对话**：使用拆段表（步骤3.4）中的旁白文本。
- 对镜说话：`The presenter (S1) says: <d>[Chinese] 旁白文本</d>`
- 画外旁白：`The presenter (S1) says in an off-screen voiceover: <d>[Chinese] 旁白文本</d> while her/his lips remain completely closed.`

**全息**：在合适镜头插入全息互动。描述四步（召唤、交互、响应、退出），使用 `references/hologram-library.md` 中的词汇。

**画面内文字**：英文双引号（如 `"16GB VRAM"`）。
- 重要：文字必须以全息文字、标志牌、标签等形式融入场景
- 禁止以字幕条形式出现在画面下方

**转场**：软甩镜头、全息擦除、匹配剪辑或发光数据带。

**目标长度**：350-500英文词。

### 5.5 overall_soundscape

1-4句英文，概括环境音和物理音。包含：
- 房间环境音（台灯嗡鸣、通风）
- 全息UI声音（提示音、数字滴答）
- 物理动作音（椅子轻响、衣物摩擦、手指点击）
- 不重复对话和音乐

### 5.6 non_diegetic_music

1-3句英文，描述背景音乐。
- 关注乐器、速度、节奏、动态变化
- 跨段保持音乐风格一致
- 无音乐时用 `N/A`

## 步骤6：校验

输出所有段的校验报告：

| 校验项 | 方法 | 通过标准 |
|--------|------|----------|
| 时长 | 最后一个镜头时间码 ≤ 段最大时长 | PASS/FAIL |
| 字数 | 统计每段 `<d>` 标签内字数 | ≤ 可用字数 |
| 文案覆盖 | 所有段旁白拼接 vs 原文 | 100%（含允许的微调） |
| 全息数量 | 统计每段全息互动数 | ≥ 2个/段 |
| 全息完整性 | 检查每个全息的召唤/交互/响应/退出 | 四步齐全 |
| 角色一致性 | 跨段比较 Subject 1 | 一致 |
| 环境一致性 | 跨段比较 Subject 2 | 一致 |
| 说话者ID | 检查 (S1) 使用 | 跨段稳定 |
| 时间码顺序 | 检查镜头时间码 | 严格递增，在范围内 |
| 格式完整性 | 检查六段式结构 | 六段齐全 |
| 无字幕 | 检查是否有字幕式文字 | 文字仅作为场景内元素 |

如有 FAIL，标注哪段哪项，修正后输出。

## 镜头与表演指南

- 第1段通常以中近景开场，然后变化角度
- 后续段使用正面构图、受控推拉和全息转场
- 讲师在面向镜头说话、指向工作区和操作全息卡片之间交替
- 动作匹配用户的风格描述，不强加固定表演风格
- 跨段连续性：同一房间、同一服装、同一眼镜、同一发型、同一全息设计系统

## 音频指南

- 旁白声音匹配用户风格描述
- 氛围音乐匹配环境氛围，低音量，跨段一致
- 全息UI声音：提示音、数字滴答、交互反馈
- 房间环境音：台灯嗡鸣、椅子轻响、衣物摩擦
- 避免大声通知、刺耳whoosh声或喜剧音效

## 文字规则

- 画面内文字必须以全息文字、标志牌、标签或数据展示形式融入场景
- 禁止生成字幕条、下沿字幕或画面底部文字叠加
- 全息文字简短可读：标签、数字、短词组
- 全息中不出现密集段落文字

## 拒绝或重写条件

- 输出是一个通用提示词而非N段独立提示词
- 忽略角色参考图、环境参考图或全息交互要求
- 改变角色身份、年龄、种族、眼镜或服装色系
- 将环境改为普通办公室或摄影棚
- 旁白节拍过长无法适配时间码
- 任一段全息互动少于2个
- 任一全息缺少四步中的任何一步
- 文案覆盖低于100%
- 文字以字幕条形式出现而非场景内元素
- 输出依赖或引用任何外部skill
