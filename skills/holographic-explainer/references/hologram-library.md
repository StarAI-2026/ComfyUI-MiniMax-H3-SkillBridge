# Hologram Type Library

## Core Rules

- Minimum 2 holographic interactions per segment
- Each holographic element must describe 4 steps: Summon -> Interact -> Respond -> Exit
- Hologram colors derive from the environment reference image, consistent across segments
- Adjacent segments should use different hologram type combinations

## Hologram Types

| Type | Use Case | Display Form | Typical Content |
|------|----------|-------------|-----------------|
| Progress bar | Install, load, timeline | Horizontal bar fill | Download progress, step completion |
| Card deck | Multiple items, tiers, options | Cards in row or fan | Hardware tiers, feature comparison |
| Data panel | Stats, specs, numbers | Panel with numbers and labels | VRAM/RAM specs, benchmark scores |
| Flow diagram | Process, pipeline, steps | Nodes and connectors | Install flow, workflow |
| Warning icon | Caution, misconception | Flashing icon with short text | "Can run... but at what cost?" |
| Confirmation badge | Success, completion | Glowing checkmark or medal | "Ready!" "Done!" |
| Timeline ribbon | Sequential events, history | Horizontal timeline with nodes | Version history, release timeline |
| Comparison board | Side-by-side contrast | Left-right split panels | Before/after, A vs B |
| 3D model rotation | Product showcase, structure | Rotatable 3D hologram | Product appearance, internal structure |
| Map/topology | Network relations, architecture | Nodes and connection lines | System architecture, network topology |
| Chart curve | Trends, performance | Line/bar chart | Performance comparison, growth curve |
| Tag cloud | Feature lists | Floating text labels | Keywords, feature collection |

## Content Matching Rules

| Script Feature | Recommended Type | Match Reason |
|----------------|-----------------|--------------|
| Numbers/specs | Data panel, card deck | Numbers need visualization |
| Steps/process | Flow diagram, progress bar | Steps need sequential display |
| Comparison/choice | Comparison board, card deck | Comparison needs side-by-side |
| Warning/question | Warning icon, flip card | Needs attention |
| Result/completion | Confirmation badge, chart curve | Needs result display |
| History/version | Timeline ribbon | Needs timeline |
| Product name/model | 3D model rotation, data panel | Needs product display |
| Trend/performance | Chart curve | Needs trend visualization |
| Architecture/relation | Map/topology | Needs relationship graph |
| Features/keywords | Tag cloud | Needs keyword highlight |

## Interaction Vocabulary

### Summon
materializes, fades in, pops up, expands from a point, slides in from [direction], bursts into view, particles converge to form, rises from the desk

### Interact
taps with fingertip, pinches to resize, flips the card, swipes across, tosses aside, rotates with hand, spreads fingers to expand, presses down, waves hand across, drags to position

### Respond
flips to reveal, expands, pulses with light, changes color, rotates, splits into multiple, merges into one, scales up/down, data flows along connections

### Exit
dissolves into particles, fades away, shrinks to a point, flies off-screen, scatters into fragments, collapses back into the device, gradient fade to transparent

## Color Rules

Hologram colors derive from the environment reference image:

| Environment Palette | Hologram Colors | Contrast Color |
|---------------------|-----------------|----------------|
| Pink tones | Pale pink + rose gold | Subtle cyan |
| Blue tones | Light blue + silver | Warm orange |
| Green tones | Light green + gold | Light purple |
| White tones | Warm white + pale gold | Light blue |
| Dark tones | Deep blue + cyan | Bright white |
| Warm wood tones | Amber + warm gold | Light green |

Hologram colors must be consistent across all segments.
