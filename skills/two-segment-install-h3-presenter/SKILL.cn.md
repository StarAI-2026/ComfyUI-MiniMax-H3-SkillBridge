# Easy Install 与 H3 双段讲解器

用此 Skill 将用户素材转化为完整的30秒中文讲解视频，输出恰好两段15秒视频提示词。目标讲师为"遇见风"，灵感来自用户提供的肖像参考图。目标环境为暖粉色奢华书房，灵感来自用户提供的房间参考图。内容整合 ComfyUI-Easy-Install 快速本地安装和 MiniMax H3 简明玩法攻略。

## 不可违反的输出契约

- 恰好输出两段最终提示词：【第1段｜0-15秒】 和 【第2段｜15-30秒】。
- 每段提示词必须可独立用于视频生成，同时保持角色、房间、灯光、服装、全息风格和镜头语言的一致性。
- 两段提示词构成一个连续的30秒体验，而非两个无关片段。
- 中文旁白/字幕使用原文语言。视觉和技术描述可使用英文，以适配视频模型的英文提示词要求。
- 不生成露骨色情内容。成熟风格意味着从容、优雅、有磁性、专业、克制、电影感。

## 角色与身份锁定

- 提供的讲师图像是身份锚点。保持面部结构、发型、眼型、眼镜、黑色蝴蝶结细节和酒红色服装。
- 讲师名称：遇见风。她是两段视频中的出镜身份。
- 风格方向：成熟亚洲女性，自信、优雅、性感但专业，平静的眼神接触，柔和微笑，精致姿态，细腻的手部动作。
- 服装锁定：深酒红色合身上衣或连衣裙，黑色丝带/蝴蝶结配饰，金丝边眼镜，黑色长发带柔和波浪，自然奢华妆容。
- 不得改变年龄段、种族、眼镜、服装色系或肖像的可辨识身份。

## 环境锁定

- 提供的粉色书房图像是环境锚点：暖粉色桌面、金色点缀、粉色椅子、花卉、书架、笔记本电脑、暖色台灯、温馨傍晚氛围。
- 将其延伸为电影级实景空间，而非单纯产品照片。每个背景都保持粉金奢华书房氛围。
- 讲师必须感觉真实存在于房间中：反射、接触阴影、暖色弹光、真实的桌面交互。

## 全息互动规则

- 在桌面或笔记本电脑上方/旁边添加雅致的全息UI元素。
- 全息影像须看起来可交互：讲师可指向、捏合、旋转、展开或翻转数据卡片和时间线节点。
- 全息影像使用浅粉色、玫瑰金、暖白色和微妙的青色对比；不得喧宾夺主。
- 仅在有用时显示可读的全息卡片：安装进度、文件解压、模型下载、依赖安装、ComfyUI启动、H3硬件档位。

## 结构与节奏

- 总计恰好30秒。
- 第1段为0-15秒，必须完成 ComfyUI-Easy-Install 安装引导。
- 第2段为15-30秒，必须完成 MiniMax H3 玩法和硬件建议。
- 每15秒段落建议3-5个镜头，有清晰转场。
- 每个旁白节拍须短到能适配时间码。
- 使用打比方。Easy Install 像打开一个整理好的行李箱/工具箱；H3档位像选择经济舱、商务舱、头等舱。

## 第1段必须内容

前15秒必须介绍并视觉演示 ComfyUI-Easy-Install 的本地安装：

1. 钩子：装ComfyUI不再需要东拼西凑。
2. 从 GitHub Windows 分支 releases 页面下载最新 ComfyUI-Easy-Install.zip。
3. 解压到新文件夹（避免 Program Files、Windows、C:\根目录；路径不含空格和特殊字符），运行 ComfyUI-Easy-Install.bat。
4. 解释它将重复的安装工作打包成预装好的行李箱/工具箱。
5. 展示进度全息图：解压、Python环境、依赖、模型文件夹检查、ComfyUI启动。
6. 以本地 ComfyUI 页面成功打开收尾，讲师转向 MiniMax H3 话题。

建议比方："不用从散装零件开始拼机器，更像打开一个标签清晰的行李箱，每样工具都已经放在该在的口袋里。"

## 第2段必须内容

后15秒必须完整讲解 MiniMax H3 的实操建议：

1. 钩子："MiniMax H3到底怎么玩？全网最全攻略玩法，它来了！"
2. 质疑8G显存能跑H3的常见说法："很多博主说8G显存就能跑H3，确实能跑，但你看过跑起来的效果和时间吗？"
3. 清晰推荐档位：
   - 入门：16G显存 + 32G内存；实际最低门槛，或等GGUF量化模型。
   - 均衡：24G显存 + 48G内存；RTX 3090是性价比之选。
   - 高端：32G显存 + 64G内存；速度更快，分辨率更好，迭代更舒适。
4. 使用全息档位卡片或发光对比面板。
5. 以果断收尾：量力而行，选好座位，开始创作。

建议比方："8G能点火起步，但就像经济舱挤长途；24G是舒适的商务舱；32G是创作者全天迭代用的头等舱。"

## 镜头与表演语言

- 第1段以讲师在粉色桌前的中近景开场，然后进入过肩笔记本/全息镜头和环境全景。
- 第2段使用更多正面讲师构图、受控推拉和全息档位弹出转场。
- 讲师应在面向镜头说话、指向笔记本和操作全息卡片之间交替。
- 动作优雅克制；不乱挥手臂，不夸张诱惑姿势，不喜剧化表演。
- 转场可使用软甩镜头、全息擦除、匹配剪辑或发光数据带。

## 音频设计

- 温暖、近距离、亲密的录音棚旁白/讲师声音。
- 柔和的奢华电子氛围音乐，低音量。
- 精致的全息UI提示音和细微的机械安装滴答声。
- 避免大声通知、刺耳谁osh声、拥挤音效或喜剧音效。

## 技术质量标准

- 首选9:16竖屏构图，除非用户指定其他宽高比。
- 电影级暖色灯光，真实皮肤着色，浅景深，干净背景分离。
- 全息文字保持简短可读，不堆砌长段落。
- 保持段落间连续性：同一房间、同一服装、同一眼镜、同一发型、同一笔记本、同一全息设计系统。

## 拒绝或重写条件

- 输出是一个通用30秒提示词而非两段15秒提示词。
- 忽略 ComfyUI-Easy-Install、MiniMax H3、全息互动或任一参考图。
- 声称 Easy Install 能魔法般安装模型或硬件驱动。
- 过度承诺8G显存足够而不讨论速度、画质和分辨率权衡。
