# Two-Segment Install and H3 Presenter

Use this Skill to turn user material into a complete 30-second Chinese explainer with exactly two 15-second video prompts. The target subject is a sensual, mature, confident female presenter inspired by the supplied portrait reference. The target environment is a warm pink luxury study inspired by the supplied room reference. The content combines ComfyUI-Easy-Install for fast local ComfyUI setup and a concise MiniMax H3 gameplay guide.

## Non-Negotiable Output Contract

- Output exactly two final prompts: `【第1段｜0-15秒】` and `【第2段｜15-30秒】`.
- Each prompt must be independently usable for video generation while preserving character, room, lighting, outfit, hologram style, and camera language.
- The two prompts must form one continuous 30-second experience, not two unrelated clips.
- Use Chinese narration/subtitle text in the original language. All visual and technical descriptions may be written in English when the video model expects English prompts.
- Do not generate explicit sexual content. Mature style means composed, elegant, magnetic, professional, controlled, and cinematic.

## Subject and Identity Lock

- Supplied presenter image is the identity anchor. Preserve face structure, hairstyle, eye shape, glasses, black bow details, and burgundy outfit.
- Presenter name: 遇见风 (Meet-the-Wind). She is the on-camera identity throughout both segments.
- Style direction: mature Asian woman, confident, elegant, sensual but professional, calm eye contact, soft smile, refined posture, subtle expressive hand movement.
- Wardrobe lock: deep burgundy fitted blouse or dress, black ribbon/bow accents, thin gold glasses, long dark hair with soft waves, natural luxury makeup.
- Do not change age category, ethnicity, glasses, outfit palette, or the portrait's recognizable identity.

## Environment Lock

- Supplied pink study image is the environment anchor: warm blush-pink desk, gold accents, soft pink chair, flowers, shelves, laptop, warm lamps, cozy evening ambience.
- Extend it into a cinematic live-action space, not a plain product photo. Keep the pink-and-gold luxury study mood in every background.
- Presenter must feel physically present in the room: reflections, contact shadows, warm bounce light, realistic desk interactions.

## Holographic Interaction Rules

- Add tasteful holographic UI elements floating above or beside the desk and laptop.
- Holograms must look interactive: the presenter can point, pinch, rotate, expand, or flip data cards and timeline nodes.
- Holograms use pale pink, rose gold, warm white, and subtle cyan contrast; they must not overpower the presenter.
- Include readable holographic cards only when useful: install progress, file extraction, model download, dependency install, ComfyUI launch, H3 tiers.

## Form and Pacing

- Exactly 30 seconds total.
- Segment 1 is 0-15 seconds and must complete ComfyUI-Easy-Install onboarding.
- Segment 2 is 15-30 seconds and must complete MiniMax H3 gameplay plus hardware recommendations.
- Prefer 3-5 shots per 15-second segment, with clear transitions.
- Keep every narration beat short enough to fit the timecode.
- Use analogies. Easy Install should feel like a well-prepared toolbox or moving box; H3 tiers should feel like choosing car seats or travel cabins.

## Segment 1 Required Content

The first 15 seconds must introduce and visually demonstrate ComfyUI-Easy-Install for local ComfyUI setup:

1. Hook: installing ComfyUI no longer needs to feel like assembling scattered parts.
2. Download the latest ComfyUI-Easy-Install.zip from the GitHub Windows branch releases page.
3. Extract the ZIP to a new folder (avoid Program Files, Windows, or C:\ root; no spaces or special characters in the path) and run ComfyUI-Easy-Install.bat.
4. Explain that it packages repeated setup work like a pre-packed suitcase/toolbox.
5. Show progress holograms: unzipping, Python environment, dependencies, model folder check, ComfyUI launch.
6. End with the local ComfyUI page opening successfully and the presenter turning toward MiniMax H3.

Suggested analogy: "It is less like building a machine from loose screws, more like opening a well-labeled suitcase where each tool is already placed in the right pocket."

## Segment 2 Required Content

The last 15 seconds must explain MiniMax H3 in a complete practical way:

1. Hook: "MiniMax H3到底怎么玩？全网最全攻略玩法，它来了！"
2. Challenge the common claim that 8GB VRAM can run H3: "很多博主说8G显存就能跑H3，确实能跑，但你看过跑起来的效果和时间吗？"
3. Recommend tiers clearly:
   - Entry: 16GB VRAM + 32GB RAM; practical minimum, or wait for GGUF quantized models.
   - Balanced: 24GB VRAM + 48GB RAM; RTX 3090 is a strong value choice.
   - High-end: 32GB VRAM + 64GB RAM; higher speed, better resolution, more comfortable iteration.
4. Use holographic tier cards or a glowing comparison board.
5. End with a decisive close: choose according to budget and patience, then start generating.

Suggested analogy: "8GB can start the engine, but it is like taking a long trip in an economy seat; 24GB is the comfortable business cabin, and 32GB is the quiet first-class setup for creators who iterate all day."

## Camera and Acting Language

- Segment 1 begins with a medium close-up of the presenter at the pink desk, then moves into over-the-shoulder laptop/hologram shots and wide environment reveals.
- Segment 2 uses more frontal presenter framing, controlled zooms, and holographic tier-pop transitions.
- The presenter should alternate between speaking to camera, gesturing toward the laptop, and manipulating holographic cards.
- Motions are elegant and economical; no chaotic arm waving, no exaggerated seductive posing, no comedic acting.
- Transitions may use soft whip pans, hologram wipes, match cuts, or glowing data ribbons.

## Audio Design

- Warm, close, intimate studio voiceover/presenter voice.
- Soft luxury-electronic ambient music, low volume.
- Delicate holographic UI chimes and subtle mechanical install ticks.
- Avoid loud notifications, harsh whooshes, crowded sound effects, or comedic stingers.

## Technical Quality Bar

- 9:16 vertical composition is preferred unless the user requests another aspect ratio.
- Cinematic warm lighting, realistic skin shading, shallow depth of field, clean background separation.
- Keep hologram text short and readable, never dense paragraphs.
- Preserve continuity between segments: same room, same outfit, same glasses, same hairstyle, same laptop, same holographic design system.

## Required Narrative Arc

- Segment 1: installation becomes calm and controlled.
- Transition: hologram shifts from install dashboard to H3 tier board.
- Segment 2: hardware confusion becomes a simple purchase decision.
- Ending: confident invitation to start creating with MiniMax H3.

- It ignores ComfyUI-Easy-Install, MiniMax H3, hologram interaction, or either supplied image reference.
- It claims Easy Install magically installs models or hardware drivers beyond what a setup package can do.
- It overpromises that 8GB VRAM is enough without discussing speed, quality, and resolution trade-offs.
- It uses explicit sexualized wording or unprofessional fashion-show posing.
